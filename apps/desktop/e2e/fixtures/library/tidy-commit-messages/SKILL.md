# Tidy commit messages

## When to use

A card asks for a commit message, or for a one-line summary of a change.

## Steps

1. Start with a verb in the present tense: "Add", "Fix", "Remove".
2. Say what changed in under 60 characters.
3. On a second paragraph, say why, if it isn't obvious.

## Done means

The message reads as one clear sentence and names the change.
